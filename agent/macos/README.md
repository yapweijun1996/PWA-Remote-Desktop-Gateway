# RDG host agent — PROTOTYPE

Status: feasibility prototype for option A (owner decision, 2026-10-04): a host agent on the Mac replaces Apple's
built-in Screen Sharing (VNC) as the input/clipboard path. It is **not** a production component, is not deployed and
is not wired into the gateway or PWA. The Guacamole/VNC path remains the supported path and the maintenance fallback.

## What it does
- ScreenCaptureKit capture of the main display (points, width capped at 1920), only when content changes.
- Real-time hardware H.264 (VideoToolbox, no reordering, keyframe on request), AVCC frames with an avcC description
  for WebCodecs.
- Keyboard and pointer injection as real macOS key codes with explicit modifier flags (Meta/Super → Command,
  Alt → Option, Control → Control), Unicode fallback for characters outside the layout, pixel scrolling.
- Plain-text clipboard both ways (≤16 KiB). Mac → client is opt-in per session, only changes after the session
  starts, and skips `org.nspasteboard.ConcealedType`/`TransientType`/`AutoGeneratedType` items.

## Security boundaries
- Listens on `127.0.0.1` only; one client at a time.
- WebSocket handshake refuses any `Origin` outside `--allow-origin` (every browser page sends one; the gateway sends none).
- First message must be `{"t":"hello","token":…}` within 2 s; the 32-byte token lives in a 0600 file
  (`~/Library/Application Support/RDG/agent.token` by default), compared in constant time, never logged.
- View-only unless `control` is requested *and* macOS has granted Accessibility to RDG Agent.
- Never prompts during a session: capture is preflighted. Permissions are requested only by the explicit
  `--request-permissions` setup run.
- Releases every pressed key and mouse button on disconnect, failure or `{"t":"release"}`.
- Logs lifecycle only — no keys, clipboard text, frames or tokens.
- Backpressure: at most one video message in flight; on congestion frames are dropped until the next keyframe.

Launch with `open` so macOS attributes permissions to RDG Agent. Started from a terminal it inherits the terminal's
grants (this happened once during development: a test captured about two seconds of the screen to a local headless
browser; nothing was stored). `test/security-checks.mjs` therefore launches the app with `open`.

## Known limits
- macOS 15+ asks again about once a month for Screen Recording unless an app has Apple's
  `com.apple.developer.persistent-content-capture` entitlement, which an ad-hoc build cannot have. Answer the prompt
  through the existing VNC path. Rebuilding changes the signature and can make macOS ask again.
- No LaunchAgent: started manually. Runs only inside a logged-in user session (not at the login window).

## Build and checks
    ./agent/macos/build.sh                      # → .tools/agent/RDGAgent.app (ad-hoc signed, com.rdg.local.agent)
    node agent/macos/test/security-checks.mjs .tools/agent/RDGAgent.app
